## 💻 Quick Start & Deployment

### 1. Start Local Development Server
```bash
npm run dev
```

### 2. Build for Production
```bash
npm run build
```

### 3. Deploy to Firebase (`rezaul-islam-7b565`)
```bash
firebase deploy
```
